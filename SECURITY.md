# Security and Privacy

This public repository is a sanitized derivative of a private operational
project. Do not add credentials, tokens, keys, recovery material, live network
or host identifiers, usernames, private paths, raw logs, sensitive screenshots,
patient data, employer-confidential information, or proprietary clinical-system
content.

Use placeholders, generalized diagrams, synthetic fixtures, and bounded
verification statements. If you believe public material exposes sensitive
information, report it privately to the repository owner rather than opening a
public issue.
